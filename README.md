# CV

Currículum vitae editable y responsivo, creado como una página web estática.

## Archivos

- `index.html`: estructura y contenido del CV.
- `styles.css`: diseño responsive y estilos de impresión.

## Vista local

```bash
python3 -m http.server 8000
```

Después, abre `http://localhost:8000` en el navegador.

## Personalización

1. Sustituye los textos de ejemplo por tus datos personales.
2. Actualiza el correo electrónico, teléfono, ubicación y LinkedIn.
3. Añade tu experiencia, educación, proyectos y certificaciones.
4. Ajusta los colores en `:root` dentro de `styles.css`.

## Publicación

Puedes publicar la carpeta mediante GitHub Pages o cualquier servicio de alojamiento estático.
